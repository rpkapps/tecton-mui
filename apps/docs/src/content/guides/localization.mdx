## The default: date-fns and en-US

Date and time pickers need a `LocalizationProvider` above them. The one exported by
`@tecton-mui/ui` is preconfigured with the `date-fns` adapter and the `en-US` locale, so no adapter
import is needed. Values are native JavaScript `Date` objects. Every Tecton application works with
dates this way: use `Date` values and `date-fns` rather than another date library.

```tsx
import { LocalizationProvider } from '@tecton-mui/ui';
import DatePicker from '@tecton-mui/ui/DatePicker';

export function StartDate() {
  return (
    <LocalizationProvider>
      <DatePicker label="Start date" />
    </LocalizationProvider>
  );
}
```

`LocalizationProvider` is deliberately separate from `ThemeProvider`, following MUI's model. Place
it once near the root of the part of your application that uses pickers, or around a single picker.

## Changing the locale

Pass a `date-fns` locale as `adapterLocale`. It controls month and weekday names, the first day of
the week and default formats:

```tsx
import { de } from 'date-fns/locale/de';
import { LocalizationProvider } from '@tecton-mui/ui';

<LocalizationProvider adapterLocale={de}>{/* pickers */}</LocalizationProvider>;
```

`date-fns` is a dependency of `@tecton-mui/ui`. If you import locales from it directly, add it to your
own `package.json` with a compatible version so your bundler resolves the same copy.

## Translating picker texts

Labels such as toolbar titles and button texts come from `localeText`. Provide the strings your
application needs; keys you omit keep their English defaults:

```tsx
<LocalizationProvider localeText={{ cancelButtonLabel: 'Abbrechen', okButtonLabel: 'OK' }}>
  {/* pickers */}
</LocalizationProvider>
```

## Component text and direction

Translations for core components (for example `TablePagination` labels) are part of the theme, not of
`LocalizationProvider`. Pass them as theme `defaultProps`, or as an extra argument to `createTheme`;
see
[ThemeProvider and shared light/dark mode](/guides/theming). Right-to-left layout is controlled by
`ThemeProvider direction="rtl"`.
