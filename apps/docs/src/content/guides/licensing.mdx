## Documentation content

- **Originally authored.** The prose, examples and demos in this portal were written for
  `@tecton-mui/ui`. They are not copied from mui.com or from MUI X documentation.
- **Familiar structure.** The portal follows the component taxonomy and page conventions that MUI
  users know (Inputs, Data Display, Feedback, and so on), so that teams can find their way around.
- **Generated API tables.** Props, events and slots are generated from the TypeScript declarations of
  the code you install. Property descriptions are taken from the type declarations (JSDoc) of the
  MIT-licensed MUI packages and of this library; links to external sites are removed.
- **No commercial MUI X material.** Documentation, screenshots, demos and text of commercially licensed
  MUI X products (Pro and Premium) are not used. Pages for independently implemented advanced
  features are written from scratch.

## Code

- MUI Core (`@mui/material`), `@mui/lab`, `@mui/system` and the Community editions of
  `@mui/x-data-grid`, `@mui/x-date-pickers` and `@mui/x-tree-view` are used under the MIT license.
  Their copyright and license notices are retained in the package's `THIRD_PARTY_NOTICES.md`.
- Advanced Data Grid, range picker and Rich Tree View capabilities are implemented independently;
  no commercial MUI X source code is used.
- The theme, design tokens, fonts CSS and icons CSS are generated from the internal Tecton design
  system. The bundled fonts (Figtree, IBM Plex Mono) are distributed under the SIL Open Font License
  1.1; their notices ship with the package.

## Branding

The portal uses the Tecton design system and this library's own name. It does not reproduce MUI's
branding or site design.

## Access

This documentation is intended for internal consumers of the library. Publishing it on a public,
unauthenticated site requires a separate decision; do not assume a private repository makes its
Pages site private.
