## Purpose

A badge attaches a count or a status dot to an icon or avatar, for example unread notifications.
Tecton adds a `shape` prop (`pill` or `rectangle`).

## Accessibility

- The badge content is not announced as part of the control's name. Include the information in the
  accessible name of the element it decorates, as the `aria-label`s above do.
- A count of `0` hides the badge unless `showZero` is set.
