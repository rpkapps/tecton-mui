## Purpose

Bottom navigation lets users switch between three to five top-level destinations of a mobile or
narrow layout with a single tap. On wider screens use a navigation drawer or tabs instead.

## Parts

- `BottomNavigation` holds the destinations and the selected `value`.
- `BottomNavigationAction` is one destination with an `icon` and a `label`. Without `showLabels`,
  only the selected action shows its label, so keep labels short and the icons recognizable.
