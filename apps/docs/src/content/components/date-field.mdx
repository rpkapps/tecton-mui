## Purpose

Fields are the text inputs used inside the pickers, without the popup: `DateField`, `TimeField` and
`DateTimeField`. They are ideal when users know the value and type it, such as dates copied from
another system or timestamps in a data-entry form.

## Controlled value

`onChange` fires on every section edit. While the value is incomplete it is an invalid `Date`; check
it before you convert or send it, as in this demo.

## Formats

`format` sets the display and typing format using `date-fns` tokens. Letters (month and weekday
names) can be typed as well: the field matches them against the locale.
`formatDensity="spacious"` adds space around separators.

<Demo name="FieldFormats" />

## Validation

Fields accept the validation props of their picker (`minDate`, `maxDate`, `shouldDisableDate`,
`minTime`…). `onError` reports the failing rule so the helper text can explain it.

## States

Fields accept the `TextField` props such as `fullWidth`, `required` and `helperText`, plus `clearable`,
`readOnly` and `disabled`.

## Customizing the input

Every field and picker renders its input with `PickersTextField`. It has the familiar `TextField`
API (`variant`, `size`, `label`, `helperText`, `error`…) but renders the value as a list of editable
sections instead of a single `<input>`, which is what makes section-by-section editing accessible.

<Demo name="FieldInputVariants" />

To give several fields the same input, replace the `textField` slot with a component built on
`PickersTextField`. Define it at module level, as here, so the fields do not remount on every render.
The slot works the same way on the pickers.

<Demo name="CustomTextFieldSlot" />

### Styling sections

Inside the input, `PickersSectionList` (exported as `Unstable_PickersSectionList`) renders one
element per section (`role="spinbutton"`) with the separators between them. Target them with
`pickersSectionListClasses` and `pickersInputBaseClasses` to style the sections without replacing
any component.

<Demo name="SectionStyling" />

## Localization

The adapter locale sets the section order, separators, digits and meridiem labels. Right-to-left
locales keep the sections in reading order.

## Accessibility

- Each section of the value is announced separately as you move with <kbd>Left</kbd>/<kbd>Right</kbd>;
  <kbd>Up</kbd>/<kbd>Down</kbd> increment, digits type, <kbd>Backspace</kbd> clears a section and
  <kbd>Ctrl</kbd>+<kbd>A</kbd> then <kbd>Backspace</kbd> clears the field.
- Empty sections show placeholders such as `MM/DD/YYYY` that reflect the locale format.
- Pasting a complete value in the field's format fills every section at once.
