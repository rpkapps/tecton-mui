## Purpose

The table components render semantic HTML tables styled by Tecton. They suit small to medium data sets
that you render yourself. For sorting, filtering, column resizing, virtualization or editing, use the
[Data Grid](/components/data-grid).

## Composing the pagination actions

`TablePaginationActions` renders the first, previous, next and last buttons of `TablePagination`. To
add something next to them, pass a module-level component to `ActionsComponent` that renders
`TablePaginationActions` with the props it receives; the built-in tooltips, labels and focus handling
stay in place. Inside a `Table`, render `TablePagination` in a `TableFooter` row.

## Accessibility

- Give the table a name with `aria-label` or a `<caption>`.
- Mark row headers with `TableCell component="th" scope="row"`; header cells in `TableHead` are
  `th` automatically.
- Align numbers to the end (`align="right"`) and keep units in the header.
- `TableSortLabel` exposes the sort direction through `aria-sort` when you set `sortDirection` on the
  header cell.
