## Overview

`RichTreeView` renders a tree from data: you pass an array of items, and the component handles
rendering, expansion and selection. It is designed for large hierarchies such as asset structures,
file systems or organisation charts. There is a single `RichTreeView` in `@tecton-mui/ui`; advanced
capabilities are enabled through props, without a separate "Pro" component or license key.

> This component is being integrated. Live demos and the generated API will appear here when it is
> released.

## Basic usage

{/* INTEGRATION: basic RichTreeView demo with an `items` array. */}

```tsx
import { RichTreeView } from '@tecton-mui/ui/RichTreeView';

const items = [
  { id: 'surveys', label: 'Surveys', children: [{ id: 'north-2025', label: 'North 2025' }] },
  { id: 'wells', label: 'Wells' },
];

<RichTreeView items={items} aria-label="Project" />;
```
