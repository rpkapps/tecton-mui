## Overview

Range pickers select a start and an end in one component: a period of days (`DateRangePicker`), a
span of time (`TimeRangePicker`) or a period with times (`DateTimeRangePicker`). Each comes in a
responsive version plus `Desktop`, `Mobile` and `Static` variants, like the single-value
[pickers](/components/date-picker). `DateRangeCalendar` and the range fields are available on their own.

The components are implemented in this library on top of the public MUI X Community picker APIs; no
commercial MUI X package is used. They read the adapter and locale from the same
[`LocalizationProvider`](/guides/localization) as the other pickers.

The value is a tuple `[start, end]`; either side can be `null` while the user is still choosing.

## Basic usage

`localeText.start` and `localeText.end` label the two endpoints. On desktop (a fine pointer) the
calendar opens in a popover with two months; on touch devices it opens in a dialog.

## Fields and calendar

`SingleInputDateRangeField` holds both dates in one text input; `MultiInputDateRangeField` uses one
input per endpoint, with section-by-section keyboard editing. `DateRangeCalendar` renders one to three
months inline.

## Validation

All validation props of the single-value pickers apply (`minDate`, `maxDate`, `disablePast`,
`disableFuture`, `minTime`, `maxTime`, …). `shouldDisableDate(day, position)` also receives which
endpoint is being edited. `onError` reports an error per endpoint, and `invalidRange` on both sides
when the start is after the end.

## Keyboard

- The fields work like the other picker fields: <kbd>Left</kbd>/<kbd>Right</kbd> move between
  sections, <kbd>Up</kbd>/<kbd>Down</kbd> change values, digits type them. The single-input fields
  accept typed text instead of per-section editing.
- In the calendar, arrow keys move between days; the first selection sets the start, the second the
  end, and the range under the pointer or focus is previewed.
- <kbd>Escape</kbd> closes the popover or dialog and returns focus to the field.
