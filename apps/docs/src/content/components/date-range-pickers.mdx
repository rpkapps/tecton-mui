## Overview

Range pickers select a start and an end value in one component: a period of days
(`DateRangePicker`), a span of time (`TimeRangePicker`) or a period with times
(`DateTimeRangePicker`). Each comes in responsive, desktop, mobile and static variants, following the
same conventions as the single-value [pickers](/components/date-picker). They are part of
`@tecton-mui/ui`, implemented independently of commercial MUI X packages, and use the same
`LocalizationProvider`.

> These components are being integrated. This page will include live demos and the generated API as
> soon as they are released.

## Basic usage

{/* INTEGRATION: basic DateRangePicker demo (controlled value as [start, end] of Date | null). */}

The planned usage mirrors the single-value pickers; the value is a tuple of start and end:

```tsx
import { DateRangePicker } from '@tecton-mui/ui/DateRangePicker';
import LocalizationProvider from '@tecton-mui/ui/LocalizationProvider';

<LocalizationProvider>
  <DateRangePicker localeText={{ start: 'Check-in', end: 'Check-out' }} />
</LocalizationProvider>;
```
