## Purpose

`ButtonBase` is the foundation of `Button`, `IconButton`, `Tab`, `ListItemButton` and the other
clickable components. It renders a `<button>` (or the element given by `component`) with keyboard
activation, focus-visible detection and the ripple, and no visual style of its own. Use it only for
custom interactive surfaces that no existing component covers.

## Before you build on it

Prefer an existing Tecton component: `Button`, `IconButton`, `ToggleButton`, `Chip`, `ListItemButton`
and `CardActionArea` already have the Tecton look and states. If you still need `ButtonBase`, set
`focusRipple` for keyboard users, describe the state with ARIA (for example `aria-pressed` for a
toggle) and keep a visible focus indicator: `ButtonBase` adds the `Mui-focusVisible` class while it
has keyboard focus.
