## Purpose

`TimePicker` enters a time of day. On desktop it opens digital lists of hours and minutes; on touch
devices an analog clock in a dialog. The date part of the value is preserved, so a time picker can edit
the time of an existing timestamp.

## Basic usage

`ampm` switches between 12- and 24-hour display (the default follows the locale). The second picker
shares the first one's value as its default and uses 15-minute steps.

## Variants

`TimePicker` is responsive. With a fine pointer it renders `DesktopTimePicker`, a popover with digital
lists for hours and minutes; otherwise it renders `MobileTimePicker`, a dialog with an analog clock.
Use a variant directly when the presentation must not change with the device.

<Demo name="TimePickerVariants" />

### Mobile clock

`MobileTimePicker` opens a dialog with a toolbar and Cancel / OK buttons, so a time is only committed
with `onAccept`. `minutesStep` limits the clock to multiples of a step, and `ampm={false}` switches to
the 24-hour face.

<Demo name="MobileHandoverPicker" />

### Static picker

`StaticTimePicker` renders the clock inline with its toolbar and action bar, for dialogs or panels that
are dedicated to choosing a time.

<Demo name="StaticClockPicker" />

`viewRenderers` chooses how each view is drawn. With `renderDigitalClockTimeView` (exported from the
package root) the inline picker shows one list of times in 30-minute steps instead of the clock face;
with `minTime` and `maxTime` it becomes a compact list of bookable slots.

<Demo name="StaticPickupSlots" />

## Views and steps

`views` selects the sections that can be edited (for example only `'hours'`, or add `'seconds'`).
`timeSteps` sets the interval of each section in the popup lists; typed values are not rounded.

<Demo name="TimePickerSteps" />

## Validation

`minTime`, `maxTime` and `shouldDisableTime` restrict the options. `onError` reports which rule the
current value breaks, so the helper text can explain it. Here the initial value is too early.

## Accessibility

- The field is keyboard-first: each part of the time (hours, minutes, meridiem) is a section. Arrow
  keys <kbd>Left</kbd>/<kbd>Right</kbd> move between sections, <kbd>Up</kbd>/<kbd>Down</kbd> change the
  value, digits type it directly.
- The open-picker button has an accessible label that includes the current value. In the popup, the
  lists are listboxes: arrow keys move, <kbd>Enter</kbd> selects and <kbd>Escape</kbd> closes and returns
  focus to the field.
- Always give the picker a `label`; describe constraints (allowed window, steps) in helper text.
- On touch devices without a fine pointer the responsive variant opens a full-screen dialog.

## Limitations

- Time ranges are provided by the separate [range pickers](/components/date-range-pickers).
- For inline time selection without a field, see the [clocks](/components/time-clock).
