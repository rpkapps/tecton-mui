## Purpose

`DateTimePicker` combines date and time entry in one field, for scheduling and timestamps. On desktop
the popup shows the calendar and the time lists side by side; on touch devices the views follow each
other in a dialog.

## Variants

`DateTimePicker` is responsive: `DesktopDateTimePicker` with a fine pointer, `MobileDateTimePicker`
otherwise. The desktop popover shows the calendar and the time lists side by side; the mobile dialog
shows one view at a time with tabs to switch between the date and the time.

<Demo name="DateTimePickerVariants" />

### Mobile dialog

The mobile dialog commits the value only when the user presses OK, which suits forms where a
half-chosen date-time must not be saved. Combine `minDateTime` with `shouldDisableTime` to restrict
both the earliest moment and the hours of the day.

<Demo name="MobileCraneLiftPicker" />

### Static picker

`StaticDateTimePicker` renders the calendar and the clock inline with a tab bar to switch between
them.

`orientation="landscape"` moves the toolbar beside the views for wide screens such as a loading-bay
kiosk. `minTime`, `maxTime` and `minutesStep` limit the clock to the bookable delivery slots.

## Validation

Validation props of both [DatePicker](/components/date-picker) and
[TimePicker](/components/time-picker) apply, plus `minDateTime` and `maxDateTime`, which limit the
date and the time together: on the first day of the window, earlier hours are disabled.

## Accessibility

- The field is keyboard-first: each part of the value (month, day, year, hours…) is a section. Arrow
  keys <kbd>Left</kbd>/<kbd>Right</kbd> move between sections, <kbd>Up</kbd>/<kbd>Down</kbd> change the
  value, digits type it directly.
- The open-picker button has an accessible label that includes the current value. In the popup,
  arrow keys move between days (or time options), <kbd>Page Up</kbd>/<kbd>Page Down</kbd> change the
  month, <kbd>Enter</kbd> selects and <kbd>Escape</kbd> closes and returns focus to the field.
- Always give the picker a `label`; describe constraints (minimum date, format) in helper text.
- On touch devices without a fine pointer the responsive variant opens a full-screen dialog.

## Limitations

- Time zones: values are local `Date` objects. Convert to and from UTC at your API boundary.
