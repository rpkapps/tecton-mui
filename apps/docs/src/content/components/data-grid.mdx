## Overview

`DataGrid` displays and edits tabular data. Out of the box it sorts, filters, paginates, selects
rows, manages columns and edits cells. Advanced capabilities (multi-column sorting, header filters,
pinning, reordering, grouping, aggregation, tree data, detail panels, cell ranges, clipboard,
server-side data and undo/redo) are switched on with their own props.

There is **one** `DataGrid` in `@tecton-mui/ui`. It wraps the MIT-licensed Community grid and adds
features implemented in this library. There are no Pro or Premium variants and no license key.
Without any advanced props the grid behaves like the Community grid: nothing is grouped, pinned or
aggregated unless you ask for it.

> **Server-side rendering:** like the Community grid, `DataGrid` renders on the client only. Server or
> static output contains no grid markup; the grid appears once the page runs in the browser. Give the
> grid a parent with a fixed height so the page does not shift when it appears.

## Basic usage

Give the grid `rows` (each with a unique `id`, or pass `getRowId`) and `columns`. The grid fills its
parent, so the parent needs a height.

## Sorting and filtering

Hold <kbd>Shift</kbd> (or <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>) while clicking a header to sort by several
columns; the order is shown as a number next to the sort arrow. `headerFilters` adds an inline filter
input below each header. The filter panel combines several conditions with AND/OR.

<Demo name="MultiSortHeaderFilters" />

## Column pinning and reordering

Pinned columns stay visible while scrolling horizontally. Pin with `pinnedColumns` /
`initialState.pinnedColumns` or from the column menu. Drag headers to reorder columns within their
section; the column menu offers the same moves for keyboard users.

<Demo name="PinningReordering" />

## Row grouping and aggregation

`rowGroupingModel` groups rows by one or more fields. `aggregationModel` maps a field to a function
(`sum`, `avg`, `min`, `max`, `size`, or your own via `aggregationFunctions`). Group rows show their
aggregates inline, and a grand total row is pinned at the bottom. The grouping column shows the
grouping values, so the example hides the source columns with `columnVisibilityModel`, as is usual
with row grouping.

<Demo name="GroupingAggregation" />

## Tree data

With `treeData`, `getTreeDataPath` returns each row's position in the hierarchy. Missing parents are
created automatically, and aggregation works on tree nodes too.

<Demo name="TreeData" />

## Master/detail

`getDetailPanelContent` renders a panel under a row; a toggle column is added automatically.
`getDetailPanelHeight` returns a height in pixels or `'auto'`.

<Demo name="MasterDetail" />

## Cell selection and clipboard

`cellSelection` lets users select rectangular ranges of cells. <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>C</kbd>
copies the range as tab-separated text, ready for spreadsheets. Pasting writes into editable columns
starting at the selected cell and goes through `processRowUpdate`, so your validation and persistence
apply.

<Demo name="CellSelectionClipboard" />

## Server-side data

Instead of `rows`, pass a `dataSource` whose `getRows` receives the current sort and filter models and
the requested row range (`start`, `end`). Return the rows and the total `rowCount`. With `lazyLoading`
the grid requests rows as they scroll into view and shows placeholder rows meanwhile. Responses are
cached in memory by default (`dataSourceCache`).

<Demo name="ServerSideData" />

## Row reordering

`rowReordering` adds a drag handle column. Keyboard users focus the handle and press

<kbd>Alt</kbd>+<kbd>Arrow Up</kbd>/<kbd>Arrow Down</kbd>. Reordering applies to flat data and is
disabled while rows are sorted, grouped or loaded from a server.

<Demo name="RowReordering" />

Row reordering works in scrolling, virtualized grids. Dragging near the top or bottom edge of the
rows scrolls them. While the dragged row is on screen the other rows slide aside to open its slot;
once it has scrolled out of view, a drop line between the rows shows where it lands. This example
also sets `pagination={false}`; the footer then shows the total row count (`hideFooterRowCount`
hides it).

<Demo name="RowReorderingVirtualized" />

## Undo and redo

`historyStackSize` keeps that many cell edits, pastes and row moves for

<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Z</kbd> and <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Shift</kbd>+
<kbd>Z</kbd>
(or <kbd>Ctrl</kbd>+<kbd>Y</kbd>). `useGridAdvancedApiRef` gives you `undo()`, `redo()`, `canUndo()`
and `canRedo()` for your own buttons. Edit a value below with a double click or <kbd>Enter</kbd>.

<Demo name="UndoRedo" />

## Imperative API

`useGridAdvancedApiRef()` creates a ref for the `advancedApiRef` prop. Through it you can read and set
multi-item sort and filter models, pin and move columns, change grouping and aggregation, expand groups
and detail panels, select cell ranges, apply batched row updates (`updateRows`) and refetch server
data. The Community `apiRef` keeps working for everything else.

## Accessibility

- The grid follows the ARIA grid pattern (`treegrid` when rows are hierarchical). Arrow keys move
  between cells, <kbd>Home</kbd>/<kbd>End</kbd> to the first/last cell of a row,
  <kbd>Page Up</kbd>/<kbd>Page Down</kbd> by a page. The focused cell or header is outlined with the
  Tecton focus ring while you navigate with the keyboard.
- With `headerFilters`, the filter row is part of the navigation: <kbd>Arrow Down</kbd> from a
  column header moves to its filter and on to the first row, <kbd>Arrow Up</kbd> goes back.
  <kbd>Arrow Left</kbd>/<kbd>Arrow Right</kbd> move to the neighbouring filter once the text cursor
  is at the start or end of the input.
- Detail panels are not navigation stops: <kbd>Arrow Up</kbd>/<kbd>Arrow Down</kbd> move from a
  row to the next row past an open panel.
- <kbd>Enter</kbd> or typing starts editing; <kbd>Escape</kbd> cancels; <kbd>Tab</kbd> leaves the
  grid.
- Column headers announce their sort state; secondary sort columns expose their priority as text.
- Group and tree rows expose `aria-level` and `aria-expanded`; <kbd>Space</kbd> on the grouping
  cell, or the toggle button in it, expands and collapses them. The count next to a group label is
  the number of rows in the group.
- Give the grid an accessible name with `aria-label` or `aria-labelledby` when several grids share a
  page.
