## Overview

`DataGrid` displays and edits tabular data: sorting, filtering, pagination, column management, row
selection and editing out of the box, and advanced capabilities such as pinning, row grouping,
aggregation, tree data and server-side data when you enable them through props.

There is **one** `DataGrid` in `@tecton-mui/ui`. It is built on the MIT-licensed Community grid, with
advanced features implemented independently in this library. There are no separate Pro or Premium
components and no license key. With default props it behaves like the Community grid; nothing is
grouped, pinned or aggregated unless you ask for it.

> The Data Grid is being integrated. Live demos and the generated API will appear here when it is
> released.

## Basic usage

{/* INTEGRATION: basic DataGrid demo (rows + columns, pagination, sorting). */}

```tsx
import { DataGrid } from '@tecton-mui/ui/DataGrid';

const columns = [
  { field: 'id', headerName: 'ID', width: 90 },
  { field: 'well', headerName: 'Well', flex: 1 },
  { field: 'depth', headerName: 'Depth (m)', type: 'number', width: 140 },
];
const rows = [
  { id: 1, well: 'A-12', depth: 3120 },
  { id: 2, well: 'B-07', depth: 2875 },
];

<DataGrid rows={rows} columns={columns} />;
```

## Accessibility

{/* INTEGRATION: keyboard and screen-reader notes verified against the implementation. */}

The grid follows the ARIA grid pattern: arrow keys move between cells, <kbd>Enter</kbd> starts editing
and <kbd>Escape</kbd> cancels, and headers announce their sort state.
