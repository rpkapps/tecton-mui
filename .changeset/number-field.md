Add `NumberField` (outlined field with stacked stepper buttons) and `NumberSpinner` (value between
decrement/increment buttons). Both build on Base UI's number field: numeric `value`/`onValueChange`,
`min`/`max`/`step`/`smallStep`/`largeStep`, locale-aware `format`, keyboard stepping and form
submission, plus the Material field props `label`, `helperText`, `error`, `size`, `fullWidth`,
`placeholder`, `inputRef`, `sx` and `slotProps`. New runtime dependency: `@base-ui/react` 1.9.0 (MIT).
